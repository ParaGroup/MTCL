int MTCL::RequestTCP::doWork ( )
inline

Attempts to advance the I/O state of this request.

  • THREAD SAFETY: This method can be called concurrently by the IO multiplexer thread (via ConnTcp::update) and the user thread (via wait()). The compare_exchange_strong guarantees that only one thread "owns" the right to perform the read/write syscall at any given time, preventing interleaved data corruption.
  • Returns
    1 if completed, -1 if failed, 0 if it yielded (EAGAIN/EWOULDBLOCK).
